# Download site assets

`looksy-icon.png` is an exact copy of the current application artwork at
`apps/desktop/assets/looksy-app-icon-master.png`. The app icon is the site logo.
The layout crops outer padding without changing its pixels.

Current native screenshots live under `captures/2026-11-17/`; fresh interaction
snapshot sequences, a real pixel comparison, and native output videos live under
`demos/2026-11-17/`. Each directory records provenance. The older output videos
retain their dates in the page captions and do not stand in for current UI.
Capture a current running build for UI updates; do not substitute development
fixtures or invent an app interface.

Fonts are self-hosted under `fonts/` with their SIL Open Font License notices.
No third-party font request or WebGL dependency is needed.
