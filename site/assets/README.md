# Download site assets

`looksy-icon.png` is an exact copy of the current application artwork at
`apps/desktop/assets/looksy-app-icon-master.png`. This app icon is the site logo;
do not substitute the older orbit mark or construct a separate wordmark.
The layout crops the artwork's outer padding without changing its pixels.

`app-preview.png` is the existing app screenshot used in the editor section.

Fonts are self-hosted under `fonts/`, with their SIL Open Font License notices.
Three.js is pinned to 0.180.0 under `vendor/three-r180/`, with its MIT license.
Both module files are required. No CDN or third-party font request is needed.
