# Real product demonstrations

Prepared November 17, 2026. See `provenance.json` for source paths, hashes,
media metadata, dates, and transformations.

- `photo-edit.mp4`: three fresh native app captures, held for 2.5 seconds each:
  original controls, +0.45 EV exposure, then 6000 K / +12% contrast. This is an
  edited snapshot sequence, not a continuous screen recording or a latency demo.
  The temporary control changes were restored to 5500 K / 0 EV / 0% contrast.
- `board-navigation.mp4`: three fresh native views of the saved La Esquina board
  project: first board, neighboring board selected, zoomed-out shared canvas.
  Only view/selection changes were made. This is also a snapshot sequence.
- `portrait-before.webp` and `portrait-after.webp`: identical photo-rectangle
  crops from the fresh native captures. The comparison uses real app pixels,
  with no website CSS filters or generated treatment.
- `timeline-output.mp4`: the completed 12-second native Timeline review excerpt
  from November 2, 2026. Re-encoded to 1280px, with audio removed. Its native
  render receipt is referenced in provenance. This is output, not current UI.
- `depth-motion.mp4`: the actual 640×512 depth-motion city-photo render from
  November 2, 2026. Video stream copied without audio. Its native depth project
  records the source photograph, model, motion settings, and 96 output frames.
- Other WebP files are first-frame video posters (Timeline poster at 2 seconds).

The MP4 sequences crop the app viewport to omit the filmstrip and resize to
1440px wide. No UI controls are reconstructed or painted onto the captures.
The current app's unsaved timeline was preserved and restored as the active
workspace after capture. Older UI recordings and UI fixtures are not included.
