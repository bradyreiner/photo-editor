Support

Public alpha support

Start with the checks below. If the problem continues, contact the support address configured for this release.

Installation

  • Download only from the official Virel Studio page.
  • On macOS, confirm the DMG and app identify a verified Virel developer and that Gatekeeper does not report damage.
  • On Windows, use VirelStudio.appinstaller when available so update checks remain registered.

Updates

  • macOS: choose Virel Studio → Check for Updates.
  • Windows: reopen the App Installer entry or launch the app to trigger the configured check.
  • Never replace an installed app with an older catalog-incompatible build without restoring a matching backup.

Create a support bundle

  1. Open Preferences → Privacy & Support.
  2. Select Create Support Bundle.
  3. Review the generated folder. Logs can contain local file paths but do not include photo bytes.
  4. Attach only the reviewed files relevant to the request.

Include in a report

Include the Virel Studio version, operating-system version, CPU architecture, what you expected, what happened, and exact reproduction steps. Do not send original client photos without permission.

Security issues

Report suspected vulnerabilities privately. Do not publish exploit details before a fix is available.
