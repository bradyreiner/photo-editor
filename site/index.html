What to try first

01

Install cleanly

Download the build for your platform and confirm the app opens from a normal install location.

02

Import a folder

Point PhotoEditor at a small photo folder and check that catalog browsing feels stable.

03

Edit and export

Make a few basic adjustments, export images, and compare the output with the preview.

04

Report friction
