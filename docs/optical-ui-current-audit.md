## Bounded Library thumbnail loop

The default online 500-asset route clears supplied thumbnail URLs in `CatalogAssetModel::updateAssets()` and exercises cold thumbnail generation. A separate `desktop_shell_large_library_unique_thumbnail_smoothness_test` now preserves 500 distinct cached-image URLs on offline catalog rows, so it exercises independent QML image sources. Its offscreen baseline is [here](/private/tmp/photo-editor-library-grid-unique-cached-profile-offscreen.log): 2,487 ms population, including 2,441 ms settling; 1,084 ms and 1,266 ms individual event-loop callbacks; 99.67% visible-ready samples; scroll p95 8.15 ms / max 10 ms; bottom readiness 16/16 at 0 ms; filter apply/clear 45/90 ms. Direct probes put `CatalogAssetModel::galleryAssets()` at 2 ms and the QML row packer at 4 ms, so those are not the measured long callback. The default cold-worker route's current offscreen receipt is [here](/private/tmp/photo-editor-library-grid-cold-worker-profile-offscreen.log): 72 ms population, 29.4% visible-ready samples, scroll p95 16 ms / max 25 ms, and filter apply/clear 32/26 ms.

These offscreen runs expose two separate tradeoffs: independent cached images arrive during motion but their initial loading stalls Qt's offscreen event loop; cold workers keep initial population responsive but fewer images are ready during motion. Neither closes the native smoothness gate. Use at most three production optimization attempts after a visible-desktop baseline is available. Require native initial-grid callbacks and filter response below 100 ms, preserve visible readiness, and guard wheel p95/max, dispatch p95/max, and population against regressions greater than 5%. Also require zero layout rebuilds for the uniform 3:2 route, at most 100 live delegates, and every bottom-viewport thumbnail ready within 50 ms. Process RSS is unavailable in this sandbox, so delegate count remains the explicit resource guard.

Completion is not yet established. This is a bounded list of implementation and proof gaps, not a request for another preference decision or an invented approval gate.
