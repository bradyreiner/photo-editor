# Text material rendering model

Looksy text materials render in `engine/src/pipeline/color_layer_runtime.cpp` after the editable text raster is prepared and before its unchanged glyph alpha is composited. The renderer uses the existing text style fields for tint, backdrop blur, transmission, edge softness, depth, and light angle. These values stay in the text recipe, so the material remains editable after save and reopen.

The material response uses the rendered glyph alpha contour as a bevel normal and infers a shallow front-face crown from the normalized text bounds and depth field. Its normalized gradient keeps the edge response stable when the text raster is produced at another output resolution. Transformed text scales its material depth and blur with the layer. Backdrop samples use bilinear interpolation, and the glass path snapshots only the lower stack before text is composited, so a refraction sample cannot feed back into the same glyph or pick up an upper layer.

Frosted glass and smoked plastic use an unpolarized dielectric Fresnel calculation with fixed indices of refraction (1.50 and 1.49). The Fresnel term divides energy between reflection, transmitted lower-stack color, and tint absorption. The alpha contour supplies an approximate edge normal and shifts the lower-stack sample by a depth-scaled offset. Frosted glass blurs its lower-stack snapshot; smoked plastic keeps it sharper. A fixed studio strip direction supplies a small reflection response that rotates with the existing light-angle control.

Soft emboss uses a diffuse response plus a GGX dielectric specular term from the same surface normal. It remains a 2D bevel treatment because text has no editable extrusion mesh.

The metal renderer uses reference conductor colors for polished chrome, silver, gold, copper, iron (the `dark_steel` preset), and titanium. The values for silver, gold, copper, iron, and titanium come from [Filament's Table 5](https://google.github.io/filament/main/filament.html), which reports metal specular colors as sRGB; the runtime decodes those values to linear RGB before using them as F0. Polished chrome uses the linear F0 in [Naty Hoffman's SIGGRAPH 2014 shading slides](https://blog.selfshadow.com/publications/s2014-shading-course/hoffman/s2014_pbs_physics_math_slides.pdf). Champagne gold, rose gold, antique brass, and black chrome remain authored finish approximations because their alloy, patina, or coating is not represented by an elemental-metal sample. The roughness and anisotropy controls remain separate from these color references.

The text tint is converted from the active working RGB through the pipeline's XYZ/D65 reference matrix. In canonical linear sRGB, the CPU compositor evaluates a Trowbridge–Reitz GGX microfacet distribution, Smith masking, and Schlick conductor Fresnel. A neutral low-frequency studio fill at scene-linear radiance 0.28 is combined with key, fill, and rim softbox samples. Each softbox has an angular radius whose quadrature approximation broadens the GGX response, giving the inferred bevel and crown normals a readable reflected sweep while retaining each finish's roughness. The resulting radiance is converted back to working RGB through the inverse matrix without clipping signed coordinates, keeping a given response stable in linear sRGB, Display P3, Rec.2020, and ProPhoto. The existing `materialTransmission` control scales the combined studio response. The microfacet model follows [PBRT's roughness chapter](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory) and [conductor BRDF](https://www.pbr-book.org/4ed/Reflection_Models/Conductor_BRDF).

These are inspectable procedural emulations, not measured or physically complete materials. F0 values are RGB approximations, not wavelength-resolved optical constants; the Filament colors are published sRGB rendering references, and the studio fill and angular softbox samples are an uncalibrated neutral lighting rig. The renderer has no scene environment map, measured BRDF data, actual bevel/extrusion geometry, or spectral Fresnel integration. The glass refraction offset is an edge-based screen-space approximation, and the studio rig cannot reproduce reflections from the photograph itself. Focused CPU invariants cover alpha, resolution scaling, published metal hue ratios, and working-space consistency, but the materials have not passed a human reference review across fonts, photographs, working spaces, or full-resolution exports. Do not describe the finishes as scientifically exact or fully qualified.
