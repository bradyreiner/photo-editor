# Mask, Layer, and Selection System Checklist

This checklist tracks the work required to make masking, selection, and layer editing feel like a professional editor. Status keys:

- `[x]` implemented and validated in the current code path
- `[~]` partially implemented; useful behavior exists but the requirement is not fully true
- `[ ]` not implemented or not proven

Scope note: the active implementation checklist is items 1-50. Future work should close those items, update statuses, and add proof notes rather than expanding the backlog. Items 51+ are archived backlog notes from earlier ideation and are not part of the active checklist unless the user explicitly promotes them.

## Layer Model and Editing Target

1. [x] Auto-create or reuse a linked adjustment layer whenever a selection mask is created.
2. [x] Show masks as child attachments under their adjustment layer in the Layers panel.
3. [x] Show a locked Base Image layer as the bottom layer.
4. [x] Make the active edit target explicit in the UI.
5. [x] Clicking a layer switches the inspector controls to that layer's values.
6. [x] Clicking a mask switches the canvas/tools to mask editing rather than color editing.
7. [x] Support clear layer states: visible, hidden, locked, solo, selected, mask-selected.
8. [x] Render thumbnails for every layer and every mask.
9. [x] Render mask thumbnails from actual alpha data rather than stale preview data.
10. [x] Render adjustment layer thumbnails with masked adjustments visible.

## Full Masked Color Editing

11. [x] Support layer-local exposure, contrast, highlights, shadows, whites, blacks, white balance, vibrance, and saturation.
12. [x] Support layer-local brightness, levels, zones, filmic shoulder/toe, and adaptive contrast.
13. [x] Support layer-local parametric tone curves.
14. [x] Support layer-local point curves for RGB, Luma, Red, Green, and Blue channels.
15. [x] Support layer-local color mixer/HSL channel edits.
16. [x] Support layer-local RGB channel mixer.
17. [x] Support layer-local black and white mixer.
18. [x] Support layer-local color grading.
19. [x] Support layer-local color replacement, skin protection, and harmony controls.
20. [x] Support layer-local LUT stack where applicable.
21. [x] Add layer-local reset per adjustment group.
22. [x] Add copy/paste layer adjustments.
23. [x] Add sync layer adjustments to selected layers.

## Mask Accuracy and Rendering

24. [x] Prefer brush stroke geometry over stale low-resolution segmentation for brush outline display.
25. [x] Rebuild brush masks at target render resolution for full-resolution renders.
26. [x] Use the same brush rasterization logic for live paint, committed mask, layer mask, outline, and final render.
27. [x] Display active mask outline from traced alpha rather than noisy RGB overlays.
28. [x] Use a single solid mask overlay color in normal editing modes.
29. [x] Hide diagnostic/noisy matte modes from normal editing.
30. [x] Provide mask overlay opacity and color controls.
31. [x] Show only the active mask/layer by default, with explicit show-all options.

34. [x] Keep color/layer adjustments in the right inspector.

## Performance and Responsiveness

42. [x] Commit expensive mask raster work after pointer release off the UI thread.
