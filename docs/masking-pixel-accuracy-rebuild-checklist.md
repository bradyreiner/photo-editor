# Masking, Brush, Selection, And Pixel Accuracy Rebuild Checklist

This checklist turns the current selection and brush accuracy plan into an implementation contract. The goal is for every mask tool to select the same image pixels the user points at, show overlays derived from the same mask that the renderer applies, stay responsive while editing, and support true pixel-level zoom, selection, and deselection.

## Completion Definition

The rebuild is complete when all primary mask tools satisfy these invariants:

- Pointer input maps through one crop/rotation/zoom-aware image-coordinate contract.
- The visible outline is either a temporary live preview or is derived from the same final alpha that preview/export rendering uses.
- Brush, lasso, smart/object, geometric, range, and retouch selections can be combined without coordinate drift.
- Pixel editing mode can zoom to individual source pixels and add/subtract exact pixels with no neighbor bleed.
- Interactive feedback stays nonblocking while final matte work settles asynchronously.
- Focused controller, render, QML, and performance proof gates pass.
