# Virel Studio 0.1.0 Alpha

This is the first public alpha build of Virel Studio for signed desktop testing on macOS and Windows.

## What is included

- Native Qt/QML desktop app shell with library, edit, masking, timeline/carousel, import, and export workspaces.
- Local-first catalog foundation backed by the app-managed PostgreSQL helper flow when no external database URL is configured.
- Photo browsing and edit workflow scaffolding around import, cull, adjust, mask, and export.
- Tone and color adjustment controls, histogram UI, tone curve UI, and preview rendering pipeline work.
- Release packaging for macOS DMG and Windows MSIX artifacts.
- Bundled Rust helper binaries for catalog and workflow support.

## What to test

- Install the app on a clean macOS or Windows machine.
- Import a small folder of photos.
- Move through the library, carousel, and edit workspace.
- Try basic tone/color adjustments and compare preview behavior.
- Try the mask workflow enough to identify confusing or broken interactions.
- Export edited images and verify the output files.
- Report crashes, installer warnings, missing files, broken previews, or confusing UI states.

## Known limitations

- This is an alpha build and is not ready for production photo libraries.
- macOS and Windows installers are published only after their platform signatures pass the release gate.
- The public alpha is free to use; optional support payments do not unlock hidden editing behavior.
- Local diagnostic logs remain on the device unless the user creates and shares a support bundle.
- Some controls and workspaces are still incomplete or may expose placeholder behavior.
- Large catalogs, unusual camera formats, and heavy batch workflows may still have reliability gaps.
- Auto-update infrastructure is not the focus of this release.

## Installation notes

Download the installer for your platform:

- macOS: `.dmg`
- Windows: `.msix`

If the app is blocked by OS security prompts, note the exact warning text and include it in feedback.
