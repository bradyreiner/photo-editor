# Direct-download candidate status — 2026-11-17

This candidate is intended for direct distribution outside app stores: Apple silicon
macOS DMG and Windows x64 MSIX/App Installer. The selected product remains Looksy
0.1.0 alpha with subscriptions and one-time licenses. Intel Mac is not selected.
The desktop now requires Qt 6.10; CI pins Qt 6.10.2 and the Windows MSVC 2022 kit.

**Public release is on hold.** No public version tag or production publication was
performed. Neither Apple Developer membership nor Windows signing credentials
exists yet, as confirmed by the release owner in this session.

## Desktop qualification result

The staged local sweep covers all 951 non-monolithic cases. Latest per-case
outcomes, after focused verification of the final fixes, are **771 passed,
170 failed and 10 skipped**. This is not a green release gate. Failed cases
include shared mask-preview source contracts, mask/layer pointer workflows,
timeline loading and interaction, preview publication, and agent report/repair
contracts. Several cases share a check; 170 failures do not mean 170 independent
product defects. They require triage and correction before release sign-off.

Portable results were retained from an isolated software-rendering sweep;
unfinished, failed and native graphics cases were retried with per-case graphics
settings and the global software override removed. Normal helper-fixture
selection was preserved. Final renderer and shutdown fixes received focused
rechecks. This is staged local evidence, not a single fresh CI run, physical
clean-machine proof, or performance qualification.

Source under final verification: `c54a05de`. Local per-case results and failures:
