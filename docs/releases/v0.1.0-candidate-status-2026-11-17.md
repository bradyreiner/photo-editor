# Direct-download candidate status — 2026-11-17

This candidate is intended for direct distribution outside app stores: Apple silicon
macOS DMG and Windows x64 MSIX/App Installer. The selected product remains Looksy
0.1.0 alpha with subscriptions and one-time licenses. Intel Mac is not selected.
The desktop now requires Qt 6.10; CI pins Qt 6.10.2 and the Windows MSVC 2022 kit.

**Public release is on hold.** No public version tag or production publication was
performed. Neither Apple Developer membership nor Windows signing credentials
exists yet, as confirmed by the release owner in this session.

## Remaining gates

- Complete the full desktop target build and non-monolithic desktop suite.
- Complete production DMG qualification. Local packaging exposed Qt modifying
  independently prepared runtime files; deployment now protects those files.
  The input search runtime also required preparation with valid local signatures
  before its receipt could be embedded. Both original checks remain enforced.
- Resolve the search runtime's minimum-OS mismatch before claiming macOS 13
  compatibility: a read-only audit of its 120 native files found a highest
  recorded minimum of macOS 26.0. The audit found no non-system absolute native
  dependencies, but that does not establish older-OS support.
- The exact normalized-code duplication check remains above its unchanged CI
  limits. After consolidating proof helpers and repeated CMake source manifests,
  the tracked-source measurement at `a97a807a` is 867 total matches (limit 732),
  including 610 production matches (limit 505). The gate has not been weakened
  or disabled.

  Catalog-helper and PostgreSQL size budgets and Qt-pruning budgets pass. The
  local package installs 1,630,491,690 bytes; the DMG is 729,893,403 bytes. Most
  duplicate groups contain vendored Python metadata, module files, headers,
  typing stubs and licenses. The largest is the independently bundled OpenSSL
  library in PostgreSQL and search. Findings are retained locally in
  `build/direct-download-candidate-2026-11-17/package-duplicate-review.json`.
  No exception was added and no frozen runtime receipt was rewritten.
