## Acceptance

Use matching release fixtures and exact correctness checks. Default: at least 20% targeted improvement, protected timing/RSS regression no more than 20% (2 ms timing noise allowance), at most three attempts per hypothesis. Async changes must report GUI dispatch and complete result time separately. Native mask acceptance additionally requires the existing 50 ms painted-frame and 250 ms HUD gates. A build or offscreen timing does not establish native UI completion.
