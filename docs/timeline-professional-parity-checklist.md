# Timeline Professional Parity Checklist

This is a post-MVP proof-gated tracker for professional parity. The active release scope is the 15-capability [Timeline MVP Checklist](timeline-mvp-checklist.md). Only work required by that checklist belongs in the MVP milestone.

An item here is checked only after its preview, persistence, export, and focused test requirements pass where applicable.

The larger 200-capability expansion and its category release gates are tracked in [Timeline Industry-Leading Checklist](timeline-industry-leading-checklist.md).
