# Looksy brand source

`looksy-logo-source.png` is the original transparent logo image supplied for the Looksy identity. The dark and light lockups in this folder are app-ready variants derived from that artwork; the white/black lettering changes while the RGB period keeps its supplied color.

`references/` keeps the supplied identity, logo-system, agent-character, and in-use boards together as the visual reference set. The desktop QML embeds the derived lockups, while `assets/looksy-rgb-orb.png` is the period crop used in compact marks and app icons.
