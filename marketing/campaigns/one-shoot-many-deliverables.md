# Campaign: One shoot, many deliverables

**Campaign promise:** Looksy gives a visual creator one place to develop photographs, shape a video timeline, and arrange a carousel from the same shoot.

**Audience:** Photographers and solo creators who shoot the material and also need to publish across social formats.

**Campaign line:** “One shoot. Three ways to tell the story.”

**Proof standard:** Show the actual source and each real output. Still photos and video clips can come from one shoot, but they remain different source files and workflows. Do not imply the timeline was made from a still RAW file or that a single export automatically creates the carousel and video. The campaign is about breadth and continuity of intent, not magic automation.


**Production status:** These are shoot briefs. Initial review cuts use labeled source imagery and development previews. See [capture status](../evidence/current-capture-status.md) for the recorded evidence and remaining capture work.

## Capture brief

Plan a compact, unbranded “morning light / small object” shoot that you own: a ceramic cup, a book, a plant, fabric, and window light. Capture 8–10 still photographs in a camera RAW format supported by the current build, plus 4–6 short video clips from the same setup. Keep the scene consistent and avoid visible commercial logos. If using a recognizable person, get a signed release before filming.

For a log-specific version, record footage in a Sony mode that actually writes **S-Log3 / S-Gamut3.Cine** metadata, or record **S-Log2 / S-Gamut** if that is the camera mode used. Preserve the originals and metadata; select the matching supported profile in the timeline and show that selection. Do not apply a Sony input transform to a generic flat-looking clip, and do not call a generic grade an S-Log workflow. Capture a second version in standard SDR if available, so the campaign can still be completed without implying all footage is log.

The output set is: (1) one edited photograph made from the genuine RAW file; (2) one 4–6 board carousel exported from the actual boards; (3) one short cut on the video timeline using the original clips. Keep the visual intention consistent by hand across the three, and label any speed-up. If an agent contributes, capture its real prompt, result, and correction separately; do not imply it created all outputs unless it actually did.

**Social color check:** For a social photo export, choose an sRGB output only if that option is present in the build. Inspect the saved file’s profile and view the exported file outside the app before saying it is an sRGB delivery. Keep this as an optional detail shot, not a color-accuracy claim.

**Rights and asset notes:** Original shoot is the cleanest rights story. Preserve original RAW/video files, capture date, camera/profile notes, releases, and exports. If supplementing with stock clips, use only a file whose exact current license covers commercial social posts/ads and keep its source/license page in the ledger. Use original room tone or a cleared ad track for the paid master.

## Assembly notes

- Keep the three outputs visually adjacent in the final campaign montage, but label them accurately: photo edit, carousel boards, video timeline export.
- For the Sony clip, record camera mode, color-space setting, media filename, and selected input profile in the capture note. Do not call it S-Log if the original clip is only a flat picture style or a stock file with no known provenance.
- Capture the full RAW import and export path. A JPEG preview of a RAW source is not enough if the post claims the original RAW was edited.
- Do not imply preview/export parity or professional color accuracy from one attractive before/after. The proof is that the real source was imported, the selected workflow is shown, and the finished file exists.
- If demonstrating sRGB, show the export option and inspect the actual saved file. Leave “accurate across every display” and similar claims out.
- Build separate 9:16 social cuts and, if needed, a wider LinkedIn version from the same clean screen capture. Keep interface text large enough to read at phone size.
