## The proposition

A creative professional returns from a shoot with a card full of photographs
and footage, and a project to deliver. Looksy helps them move from that volume
of source material to a finished set: selected photographs, a designed piece,
a complete video, and a carousel.

Looksy is introduced as a purpose-built photo and video editor with a complete
manual workflow. The film first earns that proposition through import/culling,
photographic control, layered design, a real production timeline, carousel, and
finished output. The audience sees the professional complete the work themselves.

Only after that finished manual delivery do we introduce an optional local agent.
The second proposition is a choice: work alongside assistance to handle repeat
operations and make room for more work, while retaining the native controls,
layers, masks, and edit history. AI search is part of this later optional chapter.
The agent runs a chosen local model on the same computer in the depicted mode.

The showcased agent operates existing editing tools on the professional's source
media. It does not generate replacement photographs, video, objects, or scenes.
This is an editorial boundary for the demonstrated workflow. Do not use prompt-to-
image/video imagery, invented content reveals, or a generative-media metaphor.
The film should not frame the editor as dependent on AI, or make a universal
claim about every possible model/tool configuration in the product.

## Motion direction

Use the Adobe reference's continuity: an object becomes a portal, the camera
travels through it, and the next composition grows from the previous one.
Borrow the choreography, not its character or artwork. Every handoff needs an
identifiable carried element and a designed landing.

The first test must demonstrate this directly: a vector desk, moving camera/card/
cable/drive geometry, a monitor that fills the frame, and files that become the
library. The illustration and UI should deform, unfold, reflow, and respond.
Photographs and footage belong inside this world as the working material.

- Desk → library: follow a file from physical storage into the monitor. Bezel and desk move past us at different depths; the same file settles into the contact sheet.
- Library → photo: manually pick an existing tile and grow it into its native controls. No local-model UI, AI badges, or search prompt enters the opening.
- Photo → design: separate the working photograph, mask, typography, and paint into flat planes for a short orbit. Rejoin them cleanly.
- Design → timeline: the drawn stroke straightens into the playhead; follow it into a production sequence using distinct moving sources.
- Timeline → carousel → output: match the finished image into a shared layout, unfold panels, and inspect the deliberate delivery settings. The manual job reaches a complete result.
- Finished project → optional agent: the professional opens help in the same workspace. The scene should read as an additional choice, not a missing step required to finish.
- Agent → search → batch: existing media stays visible as the selected scope. Show local processing, sample review, an approved direction, and native edit operations.
- Assisted result → human revision → desk: the result opens in the same inspector and history. Make a manual revision before pulling back to the original desk.

Use anticipation, stagger, follow-through, brief smear frames, and object-specific
settling. Camera translation should have acceleration and a clear subject to
follow. Keep copy readable on the quiet part of each move. RGB/light/caustic
patterns mark file flow, selection, processing, and optical transitions; they
should have a job inside the action.

## Music and sound

Electronic and punchy. The rejected procedural track is removed. Choose a
produced track with a hook, bass weight, useful phrase changes, and a resolved
ending. The music needs an opening pickup, momentum for the manual edit, a fuller production section, a late phrase
change for optional assistance/review, and a clean return.
The proposed seconds are editorial targets, not locked music beats.

Use selective tactile sound: card click, drive connection, a short file-flow
accent, sample approval, edit ticks, brush texture, timeline edits, and export
resolution. No voiceover. The full review draft uses A Game by Michael Ramir C from Mixkit, source seconds
8–80, with a short opening fade and a resolved tail fade. The track is a review
selection, pending user approval; tactile sound design remains to be added.
See music-shortlist.md and ../../animated-trailer/music-source.json.

## Depicted behavior and production proof

These are proposed scenes, not completed app acceptance results. Local code
inspection confirms folder/card import controls, local visual-search machinery,
local-model endpoint validation, reversible agent drafts, and history integration.
That establishes credible subjects for the story; it does not qualify the
complete pictured shoot or autonomous batch result.

Before the final trailer, produce the matching job in the real app:

| Scene claim                         | Proof required before publication                                                                                                                                                                                                                                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Batch import                        | Import a representative mixed folder/card; inspect counts, skipped/failed states, duplicate policy, and durable catalog entries.                                                                                                                                                                                           |
| AI search                           | Use the selected local search model and a real query on the shoot. Review actual matching images; do not animate invented relevance or instant indexing.                                                                                                                                                                   |
| Local model and local inference     | Connect the intended model on localhost; record the selected runtime and inference destination. Qualify this local mode. Model installation/download and optional cloud configurations are separate from local inference. Avoid an absolute claim that the entire app never uses a network.                                |
| Optional agent using existing tools | Use an ordinary prompt, review actual samples, apply to a representative selected set, inspect outliers/results, and record the model and runtime. Do not imply autonomous completion from a scripted native fixture. Do not depict generated imagery/video as agent assistance; show actual native adjustment operations. |
| Editable history/layers             | Reopen a real agent result, adjust it, undo/revert it, save, relaunch, and inspect the native state and rendered image. Not every operation automatically creates a separate layer. Depict the actual recipe, masks, layers, and history.                                                                                  |
| Full photo controls                 | Use real source-resolution image changes, including exposure, color, detail, and local edits; inspect the intended result at full resolution.                                                                                                                                                                              |
| Production timeline                 | Build/export the depicted picture, titles/effects/keyframes, grade, and audio using actual footage. Inspect playback, decoded output, and save/reopen. Existing controls do not prove every combined workflow.                                                                                                             |
| Carousel/output                     | Save/export each actual panel, dimension, format, and profile. 4K means an inspected encoded 4K result; it is not a claim of realtime playback.                                                                                                                                                                            |

Avoid universal camera-format support, RAW export, cloud-independence of optional
cloud features, training-policy promises, professional certification, or measured
time savings without matching proof. Keep these evidence notes out of the film.
